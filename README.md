# Московский паломник

Единая цифровая платформа для поиска святынь, планирования маршрутов и сопровождения паломнических поездок по Москве и Московской области.

Проект объединяет:

- публичный Laravel-сайт;
- личный кабинет паломника;
- сообщество и совместные паломничества;
- кабинеты редакторов объектов и паломнических служб;
- модераторскую и административную панели;
- REST API;
- Flutter-приложение для Android и iOS;
- аудиогиды храмов, монастырей и маршрутов.

## Актуальное состояние

- сайт и основная часть мобильного путеводителя доступны без регистрации;
- авторизация требуется только для личных действий;
- права сотрудников определяются серверной матрицей ролей;
- аудиогиды загружаются в админке и воспроизводятся на сайте и в Flutter;
- текущая версия Flutter: `0.4.1+5`;
- карта сайта и приложения работает на MapLibre;
- маршрутизация выполняется через Valhalla;
- QR-билеты проверяются сотрудниками паломнической службы.

## Роли и права

Права проверяются сервером. Скрытие пунктов меню не заменяет проверку маршрута или контроллера.

| Роль | Назначение | Основные возможности |
|---|---|---|
| `pilgrim` | Паломник | Публичный каталог, личный кабинет, бронирования, сообщество и персональные маршруты |
| `object_editor` | Редактор объектов | Только закреплённые храмы и монастыри; предложения изменений и медиаматериалов на модерацию |
| `service_manager` | Паломническая служба | Маршруты, поездки, CRM заявок, участники, QR-билеты и рабочие операции службы |
| `moderator` | Модератор | Очереди отзывов, публикаций, фотографий, посещений, жалоб, представителей и совместных паломничеств |
| `admin` | Администратор | Контент, справочники, объекты, маршруты, CRM, модерация и обычные пользователи |
| `super_admin` | Главный администратор | Полный доступ, системные настройки и назначение ролей `admin`/`super_admin` |

Обычный администратор не может назначить нового администратора или изменить другого администратора. Такие действия доступны только главному администратору.

## Аудиогиды

Аудиогид — отдельная сущность, не смешанная с обычной галереей объекта.

Поддерживается один основной аудиогид для:

- храма или монастыря;
- паломнического маршрута.

Поля:

- название;
- аудиофайл;
- текстовая расшифровка;
- MIME-тип и размер файла.

Поддерживаемые форматы:

```text
MP3, M4A, AAC, OGG, WAV, WebM
```

Максимальный размер файла: `100 МБ`.

Управление выполняется:

- в форме редактирования храма или монастыря;
- в форме редактирования маршрута;
- с автоматическим удалением предыдущего файла при замене;
- с отдельным удалением аудиогида.

На сайте и в Flutter доступны:

- воспроизведение и пауза;
- перемотка;
- изменение скорости воспроизведения;
- текстовая расшифровка;
- отдельный мобильный каталог аудиогидов.

Файлы сохраняются в:

```text
storage/app/public/audio-guides/objects/
storage/app/public/audio-guides/routes/
```

Для публичной выдачи должен существовать симлинк `public/storage`.

## Календарь, поездки и QR-билеты

Календарь поддерживает богослужения, престольные праздники, крестные ходы, поездки, лекции, встречи и другие события.

При бронировании создаются:

- код `MP-...`;
- защищённый токен;
- QR-код;
- экран и печатная версия билета;
- экспорт поездки в `.ics`.

Сканер паломнической службы:

```text
/service/tickets/scanner
```

Он фиксирует сотрудника, время проверки и количество прибывших участников, а также блокирует повторное погашение билета.

## Рабочие кабинеты

### Редактор объектов

```text
/service
/service/objects
/service/objects/{id}/edit
```

Редактор работает только с одобренными закреплениями. Изменения карточки и новые медиаматериалы создают заявку на модерацию и не попадают на публичный сайт автоматически.

### Паломническая служба

Основные разделы:

```text
/admin/crm
/admin/routes
/admin/trips
/service/tickets/scanner
```

Служба управляет маршрутами, поездками, заявками, участниками и билетами согласно серверным разрешениям.

### Модератор

Модератор получает только очереди проверки контента, жалоб и заявок. Управление системными настройками и назначение ролей ему недоступны.

### Администратор и главный администратор

```text
/admin/login
/admin
/admin/help
```

Админка включает:

- объекты и справочники;
- святыни и медиаматериалы;
- аудиогиды;
- маршруты и поездки;
- CRM и QR-билеты;
- календарь;
- модерацию сообщества;
- представителей объектов;
- пользователей и аналитику;
- журнал действий;
- системные настройки для главного администратора.

## REST API мобильного приложения

Публичные разделы:

```text
GET /api/v1/mobile/home
GET /api/v1/mobile/routes
GET /api/v1/mobile/calendar
GET /api/v1/mobile/community
GET /api/v1/mobile/community/photos
GET /api/v1/mobile/together
GET /api/v1/mobile/audio-guides
```

Карточки аудиогидов:

```text
GET /api/v1/mobile/audio-guides/objects/{object}
GET /api/v1/mobile/audio-guides/routes/{route}
```

Личные запросы защищены Sanctum. Ответ профиля содержит:

```text
role
role_label
role_description
capabilities
workspaces
```

Мобильное приложение не должно вычислять права самостоятельно: интерфейс строится по данным сервера.

## Настройки карты

Приоритет источников:

1. `MAP_STYLE_URL` — внешний `style.json`;
2. `OPENMAPTILES_TILE_URL` — внутренний векторный стиль Laravel;
3. `MAP_RASTER_TILE_URL` — растровый источник.

Основные переменные:

```env
MAP_STYLE_URL=
OPENMAPTILES_TILE_URL=
MAP_GLYPHS_URL=
MAP_RASTER_TILE_URL=https://tile.openstreetmap.org/{z}/{x}/{y}.png
MAP_TILE_MODE=cache
MAP_TILE_CACHE_DISK=local
MAP_TILE_CACHE_DIRECTORY=map-tiles/osm
MAP_TILE_CACHE_MAX_SIZE_MB=1024
MAP_TILE_DEFAULT_TTL=604800
MAP_TILE_BROWSER_TTL=86400
MAP_TILE_MAX_ZOOM=19
MAP_SATELLITE_TILE_URL=
MAP_HISTORIC_TILE_URL=
MAP_ATTRIBUTION="© OpenStreetMap contributors"
MAP_OFFLINE_ENABLED=false
MAP_OFFLINE_TILE_LIMIT=100000
VALHALLA_URL=https://valhalla.openstreetmap.de
VALHALLA_TIMEOUT=20
```

Использование публичного OpenStreetMap tile-сервера для массовой офлайн-загрузки запрещено. Офлайн-регионы включайте только с собственным или лицензированным сервером тайлов.
