# Мобильное приложение «Московский паломник»

Flutter-приложение для Android и iOS использует тот же Laravel API и ту же базу данных, что и основной сайт.

Текущая версия: `0.4.1+5`.

## Главное изменение

Приложение является публичным путеводителем и не требует обязательной авторизации при запуске.

Без входа доступны:

- главная;
- каталог храмов и монастырей;
- карточки объектов;
- карта;
- календарь;
- маршруты;
- аудиогиды;
- публикации сообщества;
- фотографии паломников;
- опубликованные совместные поездки.

Вход нужен только для личных действий: избранного, бронирований, публикаций, загрузки фотографий, вступления в поездки, персональных маршрутов и рабочих кабинетов сотрудников.

## Нижняя навигация

Основные разделы:

1. **Главная** — рекомендации, ближайшие события и маршруты.
2. **Святыни** — каталог объектов и подробные карточки.
3. **Карта** — MapLibre, геолокация и построение маршрута.
4. **События** — календарь и карточки событий.
5. **Сообщество** — публикации, фотографии и совместные поездки.
6. **Профиль / Войти** — личный кабинет после авторизации или форма входа для гостя.

Отдельный каталог **«Аудиогиды»** открывается из публичных разделов и карточек объектов/маршрутов.

## Реализовано

### Публичный путеводитель

- загрузка главной страницы из Laravel API;
- каталог храмов и монастырей;
- подробные карточки;
- изображения и святыни;
- иерархия монастырей и входящих храмов;
- места рядом;
- маршруты и календарь;
- публичное сообщество;
- общая галерея паломников;
- совместные поездки;
- аудиогиды.

### Аудиогиды

Аудиогиды доступны для храмов, монастырей и маршрутов.

Плеер поддерживает:

- воспроизведение и паузу;
- перемотку;
- отображение текущей позиции и длительности;
- изменение скорости;
- текстовую расшифровку;
- переход из общего каталога к связанному объекту или маршруту.

Используется пакет `just_audio`.

Публичные endpoint:

```text
GET /api/v1/mobile/audio-guides
GET /api/v1/mobile/audio-guides/objects/{object}
GET /api/v1/mobile/audio-guides/routes/{route}
```

### Сообщество

В отдельной вкладке доступны:

- опубликованные заметки;
- фотографии паломников;
- опубликованные совместные паломничества.

После входа пользователь может:

- создавать и редактировать публикации;
- загружать фотографии;
- отправлять материалы на модерацию;
- создавать совместную поездку;
- подавать заявку на участие;
- управлять своими группами и участниками.

### Авторизация и профиль

- регистрация и вход через Laravel Sanctum;
- безопасное хранение токена;
- локальное сохранение профиля;
- восстановление сессии при временной потере сети;
- сброс сессии только при реальном `401` или `419`;
- отображение статуса подтверждения email;
- обновление роли и разрешений с сервера.

### Роли сотрудников

Laravel передаёт:

```text
role
role_label
role_description
capabilities
workspaces
```

Flutter не вычисляет права самостоятельно. Он показывает только рабочие панели, полученные в `workspaces`.

| Роль | Что отображается |
|---|---|
| `pilgrim` | Рабочие панели отсутствуют |
| `object_editor` | Кабинет закреплённых объектов |
| `service_manager` | CRM, маршруты/поездки и QR-билеты |
| `moderator` | Очереди модерации |
| `admin` | Административные разделы согласно серверным разрешениям |
| `super_admin` | Полный административный доступ |

Если сервер явно вернул пустой массив `workspaces`, приложение не восстанавливает панели по локальной роли.

### Карта

- MapLibre Flutter;
- единый стиль с сайтом;
- OpenStreetMap / OpenMapTiles;
- маркеры храмов, монастырей, часовен и точек интереса;
- поиск объектов;
- определение местоположения;
- построение маршрутов через Valhalla;
- пеший, автомобильный, велосипедный, автобусный и мультимодальный режимы;
- офлайн-регионы при разрешённой конфигурации сервера.

### Офлайн-режим

- кэш публичных API-ответов;
- SQLite для сохранённых карточек;
- чтение ранее загруженных данных без сети;
- MapLibre OfflineManager для разрешённых офлайн-регионов;
- сохранение профиля и сессии.

Офлайн-загрузка карт должна использовать собственный или лицензированный сервер тайлов. Публичный OSM tile-сервер нельзя использовать для массовой загрузки.

## Структура API

Базовый URL передаётся через:

```text
API_BASE_URL
```

Публичные запросы:

```text
GET /mobile/home
GET /mobile/routes
GET /mobile/calendar
GET /mobile/community
GET /mobile/community/photos
GET /mobile/together
GET /mobile/audio-guides
```

Личные запросы используют Bearer-токен Sanctum:

```http
Authorization: Bearer <token>
Accept: application/json
```


`--no-fatal-infos` оставляет рекомендации анализатора в отчёте, но не завершает CI с ошибкой из-за информационных замечаний. Ошибки и предупреждения по-прежнему блокируют проверку.

## Запуск

```bash
flutter run \
  --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1 \
  --dart-define=SITE_BASE_URL=http://10.0.2.2:8000
```

Для физического устройства укажите IP компьютера в локальной сети вместо `10.0.2.2`.

## Android release signing

Для публикации в Google Play необходимо настроить собственный keystore и release signing в `android/app/build.gradle` или соответствующей Kotlin-конфигурации проекта.

Не храните:

- пароль keystore;
- пароль ключа;
- приватный `.jks`;
- production-секреты

в Git-репозитории.

## Проверка публичного режима

Перед выпуском обязательно проверить приложение без сохранённого токена:

1. удалить приложение или очистить его данные;
2. запустить без входа;
3. открыть главную, святыни, карту, события и сообщество;
4. открыть каталог аудиогидов;
5. воспроизвести аудио в карточке объекта и маршрута;
6. убедиться, что личное действие предлагает войти, а не закрывает публичный раздел.

## Проверка ролей

Для каждой служебной роли:

1. войти под отдельным тестовым пользователем;
2. обновить профиль и разрешения;
3. проверить отображаемые `workspaces`;
4. убедиться, что лишние кабинеты отсутствуют;
5. проверить, что прямой URL защищён Laravel, даже если ссылка скрыта в Flutter.

## Типовые проблемы

### После обновления осталась старая навигация

```bash
flutter clean
flutter pub get
flutter run
```

Также удалите старую установленную APK или очистите данные приложения.

### Не воспроизводится аудиогид

Проверьте:

- выполнен ли `php artisan storage:link` на сервере;
- открывается ли URL аудиофайла в браузере;
- разрешён ли HTTPS;
- корректен ли MIME-тип;
- не превышает ли файл серверные ограничения загрузки;
- передан ли правильный `API_BASE_URL`.

### Гость видит только форму входа

Убедитесь, что приложение запускает `PublicRootShell`, а не старую логику, которая показывала `AuthScreen` при `!isAuthenticated`.

### Не виден раздел сообщества

Проверьте наличие `CommunityHubTab` в публичной оболочке и публичную доступность endpoint:

```text
/mobile/community
/mobile/community/photos
/mobile/together
```

### Рабочая панель не появилась после смены роли

- нажмите обновление профиля;
- выйдите и войдите снова;
- проверьте `role`, `capabilities` и `workspaces` в ответе `/mobile/profile`;
- не добавляйте локальные исключения: источник прав — Laravel.
