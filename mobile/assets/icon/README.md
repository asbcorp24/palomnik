# Иконка мобильного приложения

`app_icon.jpg` — исходная launcher-иконка приложения «Московский паломник».

Из неё автоматически создаются системные иконки Android и iOS:

```bash
cd mobile
./tool/generate_launcher_icons.sh
```

После изменения исходника команду нужно выполнить повторно перед сборкой APK, AAB или IPA.
